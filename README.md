# hoopdeck-media

Public media for HoopDeck's social posts. The HoopDeck Content agent uploads each post's video here so Buffer can fetch it by link. Nothing here is secret: every file ends up public on Instagram and TikTok anyway.

- `videos/YYYYMMDD-<slug>.mp4`: one per post
- `shop/<product>/`: watermarked previews and listing photos for Coach Shop products (used to make Pinterest pins). Never the clean PDFs.
- `pins/YYYYMMDD-<slug>.png`: one per Pinterest pin
